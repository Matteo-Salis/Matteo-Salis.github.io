# Matteo Salis — academic personal website

A minimal, responsive academic website made with plain HTML and CSS. It has no JavaScript framework, package manager, or build step.

## Files

- `index.html` — page content and editable placeholders
- `style.css` — colors, layout, typography, and responsive styles
- `assets/profile.jpg` — add your portrait here (optional; a placeholder appears if missing)
- `files/cv.pdf` — add your CV PDF here

## Edit the site

1. Open `index.html` and replace all `[placeholder text]` entries with your details.
2. Update the biography, research topics, publication titles, author lists, years, DOIs, preprints, and repository links.
3. Add your portrait as `assets/profile.jpg`. If you prefer not to show a photo, remove the `.profile` block from `index.html`.
4. Add your PDF CV as `files/cv.pdf`. If you use another filename, update both CV links in `index.html`.
5. Update your LinkedIn, Google Scholar, GitHub, website, and other profile URLs.
6. In `style.css`, edit the variables at the top to adjust the accent color, content width, and other basics.

Important: replace placeholder URLs such as `[ADD-PROJECT-URL]` and `https://doi.org/10.0000/replace-this-doi` before publishing. Do not leave placeholder links live.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your GitHub username).
2. Upload `index.html`, `style.css`, and the `assets/` and `files/` folders to the repository root.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for deployment, then visit `https://YOUR-USERNAME.github.io`.

GitHub Pages setup documentation: https://docs.github.com/en/pages/quickstart

## Preview locally

Open `index.html` directly in your browser. Since this site uses only static HTML and CSS, no local server is required for basic previewing.
