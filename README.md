# Matteo Salis — simple academic homepage

A compact, static personal website inspired by minimal academic homepages. It uses only HTML and CSS: no JavaScript, frameworks, build tools, or dependencies.

## Before publishing
- Replace `https://scholar.google.com/` with your personal Google Scholar profile URL (there are two occurrences).
- Confirm your preferred email address.
- Add a portrait as `assets/profile.jpg` (optional).
- Add your CV PDF as `files/cv.pdf` (optional).
- Verify doctoral-study dates and degree status in the Education section.
- Edit the biography and research interests to reflect your current work.

## Publish on GitHub Pages
1. Create a repository named `YOUR-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, and the `assets/` and `files/` folders to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Visit `https://YOUR-USERNAME.github.io` after deployment.

Official guide: https://docs.github.com/en/pages/quickstart

You can preview the site by opening `index.html` in your browser.
